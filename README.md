## Featured Projects

### [TIA MCP](https://github.com/Sparkz400/TIA_MCP)
**AI-assisted engineering workflows for Siemens TIA Portal**

A Windows-based Model Context Protocol (MCP) server for working with offline Siemens TIA Portal projects. Designed around project inspection, change previews, recoverable modifications, and engineering verification.

**Technologies:** C#, .NET, Siemens TIA Openness, MCP, PLCSIM Advanced

*Active development — live Siemens runtime qualification remains in progress.*

### [Industrial Performance Dashboard](https://github.com/Sparkz400/industrial-performance-dashboard)
**Industrial monitoring and production analytics**

An industrial monitoring platform that connects machine data through OPC UA and provides live trends, historical analysis, alarm management, and auditable Overall Equipment Effectiveness (OEE) calculations.

**Technologies:** TypeScript, OPC UA, Industrial IoT, OEE

*Development software for evaluation and testing.*

### [AppSwitcher](https://github.com/Sparkz400/AppSwitcher)
**Windows application management for industrial workstations**

A native Windows application launcher and maintenance workspace designed for operator and engineering environments. Includes application supervision, browser integration, and window layout management.

**Technologies:** C#, .NET, Windows Desktop Development

*Currently in beta.*
